# バレエみくじ（フレーム）

`index.html` をブラウザで開くと動きます（スマホ表示向け）。

## ファイル構成
| ファイル | 役割 | 差し替え |
|---|---|---|
| `data/trivia.js` | バレエ豆知識の一覧 | ★ 完成した豆知識をここに追加 |
| `data/fortunes.js` | 運勢（7種）と出やすさ・一言・文字色 | ★ 確率や一言を調整 |
| `js/config.js` | 文言・操作感度・演出時間・画像パス | ★ 箱・札の画像パスを設定 |
| `css/style.css` | 見た目（`[DESIGN]` コメント箇所） | ★ デザイン確定後に調整 |
| `js/app.js` | 画面遷移・抽選・保存・ずかんのロジック | 基本は触らなくてOK |

## 仕様
- 「うらなう」→ 箱をタップで振る → 下スワイプで札が出る → 結果（上に運勢、下に豆知識）
- 1日1回（`DAY_RESET_HOUR` で日付の切り替え時刻を変更可）。引いた後は今日の結果を表示
- 引いた豆知識は自動で「ずかん」に登録（未取得は「？？？」表示、タップで詳細）
- 未取得の豆知識を優先して出す（`PREFER_UNCOLLECTED`）
- データはブラウザの localStorage に保存

## 差し替え手順
1. 豆知識：`data/trivia.js` に `{ id: "t006", title: "...", body: "..." }` を追加（id は重複不可・変更不可）
2. 箱・札の画像：`assets/` に画像を置き、`js/config.js` の `ASSETS.boxImage` / `stickImage` にパスを記入
3. 結果の札のデザイン：`css/style.css` の `.slip` 周り（運勢別は `.slip[data-fortune="daikichi"]` で指定可）

## テスト用
URL の末尾に `?debug` を付けると、タイトル画面に「今日の記録をリセット」ボタンが出て何度でも引けます。
